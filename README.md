# Autonomous Supermarket

## Project Purpose

This project simulates an autonomous supermarket operating over a 60 day period.

It generates customer demand, sales activity, operational events and business reports using a React frontend, Express backend and SQLite database.

---

## Installation

Backend

```bash
cd backend
npm install
node src/initDB.js
node src/seedProducts.js
node src/app.js
```

Frontend

```bash
cd Frontend
npm install
npm run dev
```

## Architecture

Customer demand is generated by the simulation.

The simulation sends results to SQLite.

Reporting pages read information from SQLite and display business, operational and assurance information.

Store Brain events and replenishment activity are also stored in the database.

---

## Customer Demand Model

Simulates three customer types:

- Student
- Office Worker
- Resident

Numbers vary between weekdays and weekends.

Customers are assigned shopping missions:

- Snack Run
- Lunch Purchase
- Grocery Shop

Different customer types prefer different product categories and basket sizes.

---

## Store Brain Approach

The Store Brain monitors:

- Low stock products
- Sold out products
- Replenishment activity
- Cash availability

The Store Brain generates operational events that are stored and displayed in reporting pages.

---

## Known Limitations

- Customer behaviour is simulated and not based on real supermarket data.
- Product-level reporting is limited.
- Expiry modelling is simplified.
- Replenishment lead-time modelling is simplified.
